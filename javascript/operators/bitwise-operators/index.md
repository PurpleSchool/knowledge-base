## Что такое битовые операторы

Битовые операторы работают непосредственно с двоичным представлением чисел — то есть оперируют отдельными битами, а не числами целиком. JavaScript приводит оба операнда к 32-битному целому числу со знаком (Int32), выполняет операцию над битами, а затем возвращает результат обратно в стандартное число JavaScript.

Это означает, что битовые операторы всегда работают только с целой частью числа, а дробная часть отбрасывается. Числа за пределами диапазона 32-битного целого (от −2 147 483 648 до 2 147 483 647) усекаются.

## Двоичное представление чисел

Прежде чем разбирать операторы, важно понять, как числа выглядят в двоичной системе.

```javascript
// Метод toString(2) выводит число в двоичной записи
console.log((5).toString(2));   // "101"
console.log((13).toString(2));  // "1101"
console.log((255).toString(2)); // "11111111"

// parseInt с основанием 2 делает обратное
console.log(parseInt('1101', 2)); // 13
```

Число 13 в двоичном виде — `1101`, что означает:
- разряд 3 (значение 8): 1
- разряд 2 (значение 4): 1
- разряд 1 (значение 2): 0
- разряд 0 (значение 1): 1

Итого: 8 + 4 + 0 + 1 = 13.

Отрицательные числа хранятся в формате **дополнительного кода** (two's complement): старший бит равен 1, а само значение получается инверсией всех битов плюс единица. Например, −1 в 32-битном виде — это `11111111 11111111 11111111 11111111`.

## Оператор AND (&)

Возвращает 1 в каждом разряде, где оба операнда имеют 1.

```javascript
console.log(5 & 3);
// 5:  101
// 3:  011
// &:  001 → 1

console.log(12 & 10);
// 12: 1100
// 10: 1010
// &:  1000 → 8
```

### Практическое применение AND: проверка чётности

Самый последний бит числа равен 1 у нечётных чисел и 0 у чётных. AND с единицей позволяет это проверить быстрее, чем операция `%`.

```javascript
function isEven(n) {
  return (n & 1) === 0;
}

console.log(isEven(4));  // true
console.log(isEven(7));  // false
console.log(isEven(-2)); // true
```

### Проверка битового флага

```javascript
const READ    = 0b001; // 1
const WRITE   = 0b010; // 2
const EXECUTE = 0b100; // 4

const permissions = READ | WRITE; // 3 → 011

// Проверяем наличие права на запись
if (permissions & WRITE) {
  console.log('Запись разрешена');
}

// Проверяем наличие права на выполнение
if (permissions & EXECUTE) {
  console.log('Выполнение разрешено'); // не выведется
}
```

## Оператор OR (|)

Возвращает 1 в каждом разряде, где хотя бы один из операндов имеет 1.

```javascript
console.log(5 | 3);
// 5: 101
// 3: 011
// |: 111 → 7

console.log(12 | 10);
// 12: 1100
// 10: 1010
// |:  1110 → 14
```

### Практическое применение OR: установка флага

```javascript
const READ    = 0b001;
const WRITE   = 0b010;
const EXECUTE = 0b100;

let permissions = READ; // только чтение

// Добавляем право записи
permissions = permissions | WRITE;
console.log(permissions.toString(2)); // "11" → READ + WRITE

// Добавляем право выполнения
permissions |= EXECUTE;
console.log(permissions.toString(2)); // "111" → все права
```

### Быстрое усечение до целого

OR с нулём приводит операнд к 32-битному целому, отбрасывая дробную часть. Это аналог `Math.trunc`, но работает только в диапазоне 32-битных чисел.

```javascript
console.log(3.7 | 0);   // 3
console.log(-3.7 | 0);  // -3
console.log(3.2 | 0);   // 3
```

## Оператор XOR (^)

Возвращает 1 в каждом разряде, где операнды **различаются** (исключающее ИЛИ).

```javascript
console.log(5 ^ 3);
// 5: 101
// 3: 011
// ^: 110 → 6

console.log(12 ^ 10);
// 12: 1100
// 10: 1010
// ^:  0110 → 6
```

### Практическое применение XOR: переключение флага

```javascript
const READ  = 0b001;
const WRITE = 0b010;

let permissions = 0b011; // READ + WRITE

// Переключаем флаг WRITE (если был — снимаем, если не было — ставим)
permissions ^= WRITE;
console.log(permissions.toString(2)); // "1" → только READ

permissions ^= WRITE;
console.log(permissions.toString(2)); // "11" → снова READ + WRITE
```

### Обмен переменных без временной переменной

Классический трюк с XOR: применив его трижды, можно поменять значения двух переменных местами без третьей.

```javascript
let a = 5;
let b = 3;

a = a ^ b; // a = 6
b = a ^ b; // b = 5
a = a ^ b; // a = 3

console.log(a, b); // 3 5
```

В реальном коде этот приём хуже читается, чем деструктуризация `[a, b] = [b, a]`, поэтому используйте его только там, где важна микрооптимизация.

### Проверка: числа различаются?

```javascript
function areDifferent(a, b) {
  return (a ^ b) !== 0;
}

console.log(areDifferent(5, 3)); // true
console.log(areDifferent(5, 5)); // false
```

## Оператор NOT (~)

Унарный оператор — инвертирует все биты операнда. Формула: `~n === -(n + 1)`.

```javascript
console.log(~5);  // -6
console.log(~-1); // 0
console.log(~0);  // -1
```

### Поиск в массиве: устаревший паттерн

До появления `Array.prototype.includes` программисты использовали `~indexOf()`: если элемент не найден, `indexOf` возвращает −1, а `~(-1) === 0` — ложное значение.

```javascript
const fruits = ['apple', 'banana', 'cherry'];

// Старый стиль
if (~fruits.indexOf('banana')) {
  console.log('Найдено');
}

// Современный стиль (предпочтительно)
if (fruits.includes('banana')) {
  console.log('Найдено');
}
```

### Двойное NOT: быстрое приведение к целому

```javascript
console.log(~~3.7);  // 3
console.log(~~-3.7); // -3
```

Аналогично `n | 0`, но синтаксически выражает намерение усечения. Работает только в диапазоне 32-битных чисел — для больших чисел используйте `Math.trunc`.

## Оператор левого сдвига (<<)

Сдвигает биты влево на указанное число позиций. Каждый сдвиг влево эквивалентен умножению на 2.

```javascript
console.log(1 << 0); // 1
console.log(1 << 1); // 2
console.log(1 << 2); // 4
console.log(1 << 3); // 8
console.log(1 << 4); // 16

console.log(5 << 2);
// 5:    00000101
// << 2: 00010100 → 20 (5 × 4)
```

### Генерация констант степеней двойки

```javascript
const KB = 1 << 10; // 1024
const MB = 1 << 20; // 1 048 576
const GB = 1 << 30; // 1 073 741 824

console.log(KB); // 1024
console.log(MB); // 1048576
```

### Создание масок флагов

```javascript
const FLAG_A = 1 << 0; // 0001
const FLAG_B = 1 << 1; // 0010
const FLAG_C = 1 << 2; // 0100
const FLAG_D = 1 << 3; // 1000

let state = FLAG_A | FLAG_C; // 0101
console.log(state & FLAG_A ? 'A включён' : 'A выключен'); // A включён
console.log(state & FLAG_B ? 'B включён' : 'B выключен'); // B выключен
console.log(state & FLAG_C ? 'C включён' : 'C выключен'); // C включён
```

## Оператор правого сдвига (>>)

Сдвигает биты вправо, сохраняя знаковый бит (арифметический сдвиг). Каждый сдвиг вправо эквивалентен делению на 2 с округлением к нулю.

```javascript
console.log(16 >> 1); // 8
console.log(16 >> 2); // 4
console.log(16 >> 3); // 2

console.log(-16 >> 1); // -8 (знак сохраняется)

console.log(5 >> 1);
// 5:   00000101
// >> 1: 00000010 → 2 (целочисленное деление 5 / 2)
```

### Быстрое целочисленное деление на степень двойки

```javascript
function half(n) {
  return n >> 1;
}

console.log(half(100)); // 50
console.log(half(7));   // 3 (аналог Math.trunc(7 / 2))
```

## Оператор беззнакового правого сдвига (>>>)

Сдвигает биты вправо, заполняя левые позиции нулями — знаковый бит не сохраняется. Результат всегда неотрицательное 32-битное число.

```javascript
console.log(16 >>> 1);  // 8
console.log(-1 >>> 0);  // 4294967295 (максимальное 32-битное без знака)
console.log(-16 >>> 1); // 2147483640 (не −8!)
```

Этот оператор полезен, когда нужно гарантированно получить беззнаковое целое.

```javascript
// Пример из реализации хэш-функций
function toUint32(n) {
  return n >>> 0;
}

console.log(toUint32(-1)); // 4294967295
console.log(toUint32(5));  // 5
```

## Работа с цветами через битовые операторы

Цвета в формате HEX (`#RRGGBB`) удобно разбирать битовыми операторами: цвет — это три байта, упакованные в одно 24-битное число.

```javascript
const color = 0xFF8C00; // тёмно-оранжевый

const red   = (color >> 16) & 0xFF; // 255
const green = (color >> 8)  & 0xFF; // 140
const blue  =  color        & 0xFF; // 0

console.log(`R: ${red}, G: ${green}, B: ${blue}`);
// R: 255, G: 140, B: 0

// Сборка цвета из компонентов
function toHex(r, g, b) {
  return ((r << 16) | (g << 8) | b).toString(16).padStart(6, '0');
}

console.log('#' + toHex(255, 140, 0)); // #ff8c00
```

## Система разрешений с битовыми масками

Битовые флаги — стандартный способ компактно хранить набор булевых состояний. Вместо объекта с несколькими полями используется одно целое число.

```javascript
const Permission = {
  NONE:    0b00000, // 0
  READ:    0b00001, // 1
  WRITE:   0b00010, // 2
  DELETE:  0b00100, // 4
  ADMIN:   0b01000, // 8
  OWNER:   0b10000, // 16
};

function hasPermission(userPerms, permission) {
  return (userPerms & permission) === permission;
}

function addPermission(userPerms, permission) {
  return userPerms | permission;
}

function removePermission(userPerms, permission) {
  return userPerms & ~permission;
}

function togglePermission(userPerms, permission) {
  return userPerms ^ permission;
}

// Использование
let userPerms = Permission.READ | Permission.WRITE; // 3

console.log(hasPermission(userPerms, Permission.READ));   // true
console.log(hasPermission(userPerms, Permission.DELETE)); // false

userPerms = addPermission(userPerms, Permission.DELETE);
console.log(hasPermission(userPerms, Permission.DELETE)); // true

userPerms = removePermission(userPerms, Permission.WRITE);
console.log(hasPermission(userPerms, Permission.WRITE));  // false
```

## Когда использовать битовые операторы

Битовые операторы стоит применять в следующих случаях:

- **Флаги и маски** — хранение набора булевых значений в одном числе (права доступа, состояния интерфейса, конфигурация).
- **Работа с цветами** — разбор и сборка HEX-цветов.
- **Низкоуровневые алгоритмы** — хэширование, сжатие, работа с бинарными протоколами.
- **Оптимизации** — усечение до целого (`n | 0`, `~~n`), проверка чётности (`n & 1`).

Избегайте битовых операторов там, где обычная арифметика или булевая логика читается яснее. `Math.floor` понятнее `n >> 0` для большинства разработчиков. Правило простое: если выгода в читаемости или производительности не очевидна — используйте стандартные операторы.
