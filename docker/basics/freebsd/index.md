## Введение

Docker — это платформа программного обеспечения, которая позволяет разработчикам быстро создавать, развёртывать и запускать приложения в контейнерах. Контейнеры упаковывают приложение с его зависимостями в стандартную единицу разработки и развертывания, что делает приложения портативными и более предсказуемыми в различных окружениях.

Демон Docker нативно на FreeBSD не работает: ему нужны механизмы ядра Linux, такие как cgroups и namespaces. Рабочий путь — запустить демон в виртуальной машине с Linux на встроенном гипервизоре `bhyve`, а на самой FreeBSD использовать клиент `docker`. Этот вариант мы и рассмотрим.

### Шаг 1: Установка пакетов

`bhyve` входит в базовую систему FreeBSD. Для удобного управления виртуальными машинами установим `vm-bhyve`, а также загрузчик для Linux, прошивку UEFI и клиент Docker:

```shell
sudo pkg install -y vm-bhyve grub2-bhyve bhyve-firmware docker
```

### Шаг 2: Настройка vm-bhyve

Создадим каталог для виртуальных машин и включим сервис. Если вы используете ZFS, вместо каталога можно указать датасет в формате `zfs:zroot/vm`.

```shell
sudo mkdir -p /vm
sudo sysrc vm_enable="YES"
sudo sysrc vm_dir="/vm"
sudo vm init
sudo cp /usr/local/share/examples/vm-bhyve/* /vm/.templates/
```

Теперь создадим виртуальный коммутатор и подключим его к сетевому интерфейсу. Вместо `em0` укажите имя своего интерфейса из вывода `ifconfig`:

```shell
sudo vm switch create public
sudo vm switch add public em0
```

### Шаг 3: Создание виртуальной машины с Linux

Скачайте установочный образ Debian и запустите установку. Актуальное имя файла смотрите на [странице загрузки Debian](https://www.debian.org/distrib/netinst).

```shell
sudo vm iso https://cdimage.debian.org/debian-cd/current/amd64/iso-cd/<имя-образа>.iso
sudo vm create -t debian -s 20G docker
sudo vm install docker <имя-образа>.iso
sudo vm console docker
```

В консоли пройдите обычную установку Debian и включите SSH-сервер. Чтобы машина запускалась при старте системы, добавьте её в автозапуск:

```shell
sudo sysrc vm_list="docker"
```

### Шаг 4: Установка Docker в виртуальной машине

Подключитесь к виртуальной машине по SSH и установите Docker официальным скриптом:

```shell
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
```

Выйдите из сессии и подключитесь снова, чтобы применилось членство в группе `docker`.

## Настройка Docker

### Подключение клиента на FreeBSD

Настройте вход по SSH-ключу и укажите клиенту на FreeBSD адрес демона. Вместо `user` и `192.168.1.50` подставьте пользователя и IP-адрес виртуальной машины:

```shell
ssh-copy-id user@192.168.1.50
export DOCKER_HOST=ssh://user@192.168.1.50
```

Чтобы настройка сохранялась, добавьте `export` в профиль вашей оболочки. Не открывайте TCP-порт демона без TLS: доступ к нему равнозначен правам root на виртуальной машине.

### Проверка работоспособности Docker

Убедимся, что клиент видит демон и может запускать контейнеры:

```shell
docker version
docker run --rm hello-world
```

Команда `hello-world` запускает простой контейнер, который выводит сообщение об успешной установке. Учитывайте, что контейнеры работают внутри виртуальной машины: опубликованные порты доступны по её IP-адресу, а тома монтируются из её файловой системы.
